# Local sample photographs

These four photographs are local development assets for the photo features.
They were taken by repository contributor **pschol83** and supplied directly
for this project on 2026-10-14. They show dogs and food; they are not production
photographs taken in Bali or Vientiane. Any place or coordinate assignments in
the sample dataset are fictional.

## Files

- [`images/schilln.jpeg`](images/schilln.jpeg)
- [`images/knuddeln.jpeg`](images/knuddeln.jpeg)
- [`images/kuscheln.jpeg`](images/kuscheln.jpeg)
- [`images/noDogorCat.jpeg`](images/noDogorCat.jpeg)

When the app is running, each file is available at
`http://localhost:3000/sample-images/<filename>` without Cloudflare settings or
login. The main [README](../README.md#local-sample-photos) describes starting the
app and seeding the matching database rows.

The repository copies were resized proportionally to a maximum of 1280 pixels
on their longest side and re-encoded as JPEG at quality 82. EXIF orientation was
applied before resizing. All JPEG metadata segments, including EXIF, GPS, XMP,
comments, and embedded profiles, were omitted from the copies. The originals
were not modified and are not included in the repository.
